# 2026-10-26 工作日志

## BrandStudio 前端 v0.1.0 界面优化（已交付）

### 需求
1. 左侧导航重构：模板库拆「图片类目 / 视频类目」两个独立板块分组展示；顶部导航新增「首页」「我的作品」
2. 顶部「剩余额度」悬停浮出「充值」「用户设置」
3. 首页改为上 75% 预览区 + 下 25%「快捷创作」栏（图片生成 / 视频生成）
4. 全局统一「返回上一页」

### 关键实现决策
- **版本号规则**：`v0.1.n`，本次 v0.1.0，后续递增（`frontend/src/version.js` 的 `APP_VERSION` 统一维护，
  侧栏底部 / 页脚 / 设置页展示；`CHANGELOG.md` 追加条目）
- **返回上一页**：在 `main.js` 内维护 `historyStack` 访问栈 + `location.hash` 同步（`suppressHash` 标志避免重复渲染），
  浏览器前进/后退与内部栈自动对齐；顶栏返回按钮全局常驻，无来源页时置灰
- **路由**：改为带 `:id` 参数匹配的路由表（`matchRoute`），模板详情从弹窗升级为独立页 `/templates/:id`
- **首页 75/25**：`grid-template-rows: minmax(0,3fr) minmax(0,1fr)` + `height: calc(100vh - 190px)`；
  注意必须用**确定高度**而非 min-height，否则内容会把行撑高、比例失真；预览区内部滚动 + 底部渐隐
- **侧栏分组**：数据由 `GET /api/templates` 实时聚合（按 category 分组、type 决定归属图片/视频板块），带模板计数
- **充值/设置页**为纯前端演示：`addCredits` / `getProfile` / `setProfile` / `resetLocalData` 写 localStorage
  （`bs-wallet` / `bs-profile`），老用户额度不受影响

### 验证方式（可复用）
- `node tools/page-check.mjs <宽> <高> [hash]`：Node 22 内置 WebSocket 驱动本机 Edge CDP，
  输出视口宽度 / scrollWidth / 溢出元素清单 / 页面标题 / 控制台报错
- 注意：Edge headless 的 `--window-size=375` 有最小窗口宽度限制，直接 `--screenshot` 会截断，
  需用 CDP `Emulation.setDeviceMetricsOverride` 做真实 375px 验证（结论：各断点均无横向溢出）

### 结论
10 条路由全部正常渲染、0 控制台报错；375/768/1440 无横向溢出；首页行高实测 520.5 / 173.5（精确 75:25）；
返回链路（分类→详情→返回、我的作品→充值→返回）均正确回到来源页。
