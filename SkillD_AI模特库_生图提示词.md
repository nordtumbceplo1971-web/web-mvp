# AI 模特库 · 生图提示词（欧美市场 / 5男5女 / 白T基础款）

> **用途**：建立一套可复用的 AI 服装模特库，用于白 T 恤、街头潮流类单品的换装展示与详情页/主图拍摄替代。
> **画布规格**：16:9 横向
> **三视图排版**：左侧 1/2 = 全身像｜右侧上半 = 半身像（正面）｜右侧下半 = 转身半身像（背对镜头）
> **统一设定**：20–25 岁、海外（欧美）面孔、浅至中等肤色、身材匀称修长（"穿什么都搭"的衣架子身形）、上身一律纯白 T 恤、配饰随机不雷同、表情自然不僵硬
> **风格主轴**：潮流 / 时尚 / 小众文化 / 街头文化

## 四、使用与出图建议

**1. 一致性控制**
- 同一模特的多套换装图，必须固定"Subject"整段（五官、发型、肤色、身高比例）只替换"Outfit"段，能显著降低脸型漂移。
- 生成后若三视图之间出现人脸或服装不一致，用局部重绘（inpaint）单独修其中一格，不要整张重 roll。

**2. 版式校准**
- 若模型把三个视图排成等大横排，可在 prompt 开头补一句强调：`strict three-panel layout: left panel occupies exactly 50% of the canvas width, right column split into two equal quadrants stacked vertically`。
- 16:9 在多数工具里对应 `--ar 16:9`（Midjourney）或宽高比参数，SD 系列建议直接设定 `1920×1080`。

**3. 白 T 恤的"准白"控制**
- 纯白 T 在柔光棚里容易过曝丢失褶皱层次，可在 Lighting 段追加 `exposure compensated for white garment, visible fabric folds and soft shadows in the white cotton`，保证白 T 上仍有可读的面料纹理与体积感。

**4. 肤色与市场定位**
- 全套模特肤色覆盖：冷调苍白（M-01 / F-03）、浅暖白（M-04 / F-05）、浅橄榄（M-03 / F-02）、自然白（M-02 / F-01 / M-05），统一规避深肤色，符合欧美快时尚与街头品牌的主流 cast 偏好，同时保留面部辨识度差异。

**5. 小众文化标签的视觉落点**
- 潮流/时尚 → 廓形（oversized 落肩、宽腿、高腰压褶）
- 小众文化 → 配饰细节（穿孔、choker、机能扣具、编织手环）
- 街头文化 → 鞋款（板鞋、篮球鞋、战术跑鞋）+ 下装（工装、破坏丹宁、降落伞裤）
